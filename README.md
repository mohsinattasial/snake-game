# Neon Snake — Pygame

A graphical Snake game featuring visual effects, scoring and keyboard controls.

## Setup
```bash
python -m pip install -r requirements.txt
python snake_game.py
```

**Controls:** Arrow keys/WASD to move, P to pause, R to restart after game over and ESC to quit.

- `snake_game.py`: game application.
- `requirements.txt`: pygame dependency.

Requires a graphical environment. Author: Mohsin Atta.
